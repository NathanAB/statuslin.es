# Fonts

## hanken-grotesk-regular.ttf, hanken-grotesk-semibold.ttf

**[Hanken Grotesk](https://github.com/marcologous/hanken-grotesk)**, the interface font
(`--font-sans` in `../../styles/app.css`), at weights 400 and 600 for the home share card's headline
and lead. satori can't read the site's variable woff2 (`../../styles/fonts/`), so the cards use these
two static TTFs.
