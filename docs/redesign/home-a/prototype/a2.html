How installing works

Every status line here was read by a person and rendered in a sandbox before it went up. Installing one is a single paste.

First, paste its install prompt into Claude Code.

1. Save this script to ~/.claude/statusline.sh, then run `chmod +x ~/.claude/statusline.sh`:

````
#!/usr/bin/env bash
# cc-statusline — two-line Claude Code status line, pure POSIX shell + awk.
# Reads the status JSON on stdin; needs no node/bun/jq. git & kubectl are
… 215 more lines
````

2. In ~/.claude/settings.json, set "statusLine" to { "type": "command", "command": "~/.claude/statusline.sh" }. Merge it into my existing settings — do NOT overwrite my other keys.
